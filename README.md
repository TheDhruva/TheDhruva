## 🔥 Featured Projects

### 1. AI Agent Builder — Visual No-Code Agent Orchestration Platform

> **Problem:** Developers waste weeks wiring up multi-step AI agent workflows in code — with no way to visualize, debug, or iterate fast.

**Built:** A drag-and-drop node editor where each canvas node maps to a real AI task (tool call, prompt chain, decision branch) — assembled into executable OpenAI agent pipelines at runtime. Zero code required.

| Signal | Detail |
|---|---|
| 🧩 Architecture | React Flow node graph → OpenAI Agents SDK → Convex serverless backend |
| ⚡ Real-time sync | Zero data loss on complex multi-node graphs across concurrent sessions |
| 🔒 Security | Arcjet bot protection + Clerk auth — rate limiting, bot fingerprinting, per-user route isolation |
| 🚀 Scale | Production-grade; handles multi-node agent graphs with live state sync |

**Stack:** `Next.js 15` `TypeScript` `OpenAI Agents SDK` `React Flow` `Convex` `Clerk` `Arcjet`

### 2. AI Resume Builder — SaaS with Gemini-Powered ATS Optimization

> **Problem:** Job seekers write generic bullet points that fail ATS filters — wasting hours for a 2% interview rate.

**Built:** Full-stack SaaS where Gemini API auto-generates ATS-optimized, metric-driven bullet points from a job title — delivered in under 2 seconds. Live dual-pane preview, PDF export, and recruiter-shareable public links.

| Signal | Detail |
|---|---|
| ⚡ Speed | Gemini API returns role-specific bullets in < 2 seconds |
| 🔄 Real-time | Dual-pane editor syncs form state to live preview — no debounce, no polling |
| 🔗 Sharing | Unique public resume URLs; recruiters access without login |
| 🔒 Auth | Clerk + Convex per-user data isolation across serverless functions |

**Stack:** `React 19` `Convex` `Gemini API` `Clerk Auth` `React Router v7`

### 3. Sentiment Analysis Engine — Production ML at 100K+ Row Scale

> **Problem:** Manual review analysis doesn't scale. Processing 100K+ reviews crashes naive pipelines.

**Built:** End-to-end NLP pipeline with chunked CSV processing (10K rows/chunk), XGBoost classification, and a Neubrutalism Streamlit UI with real-time confidence charts and downloadable results — deployed on Vercel Python runtime, no infrastructure needed.

| Signal | Detail |
|---|---|
| 🧠 ML Pipeline | Preprocessing → Count Vectorizer → MinMax scaling → XGBoost |
| 📦 Scale | 100,000+ row datasets via memory-efficient chunked Pandas reads |
| ⚡ Speed | 100–200ms inference per prediction in production |
| 🚀 Deploy | Serialized model artifacts on Vercel Python runtime — zero infra overhead |

**Stack:** `XGBoost` `Scikit-learn` `NLTK` `Streamlit` `Pandas` `Vercel Python`
